# Network Automation Backup

Projeto de automação de backup multi-vendor utilizando Python + Netmiko.

## Features

- Huawei
- Nokia
- Juniper
- Auto detect vendor
- Conexão via Bastion
- Multi equipamentos
- Backup automático

## Tecnologias

- Python
- Netmiko
- SSH
- Git

## Como executar

```bash
python main.py
```

## Exemplo

```text
Quantos equipamentos: 2
IP 1: 192.168.127.10
IP 2: 192.168.126.17
```

## Estrutura

```text
config/
tasks/
backups/
main.py
```
